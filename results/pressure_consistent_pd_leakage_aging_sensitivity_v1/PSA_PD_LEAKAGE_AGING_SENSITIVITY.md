# Finite Pd leakage and aging sensitivity

The original 0.4799-m² Pd design tolerates only **7.84%** permeance loss while retaining all 16 direct engineering events under effectively infinite selectivity.

A design intended to retain only 80% of the source permeance requires **0.553 m²** of Pd area and a co-sized **1.2145-mol** product receiver. This is **15.23%** more Pd area than the literature-bounded reference.

The minimum common effective-selectivity multiplier is **16.7794** relative to the stage-1 screening requirements. Applying a 25% guard band gives **20.98×** and passes **16/16** direct cases.

The maximum passing H2-equivalent Knudsen defect conductance ratio is **3.504e-05**. This is a conductance ratio, not a pinhole-area fraction.

The available public experiments do not report all four project impurity limits together at matching detection limits. The result therefore defines module acceptance tests; it does not certify an existing membrane.
